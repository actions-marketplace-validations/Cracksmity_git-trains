Design the look of the **departures board** card in `src/cards/board.js`: a split-flap station board that lists a GitHub user's most recently pushed repositories. It is meant for a profile README, so it must be beautiful, readable at its real size, and fully self-contained.

Context: git-trains writes small SVG profile cards (see `src/cards/profile.js`: the stats and languages cards, drawn with `shell()` and inline CSS, all animation is CSS inside the SVG because READMEs embed SVGs with `<img>`, where scripts and external files never run). `src/cards/departures.js` (already written, read it) turns repositories into the rows of the board and calls `renderBoard(board, style)` in `src/cards/board.js`. `src/cards/board.js` currently holds a **placeholder** renderer (plain text, no board). Replace it with the real board. The contract (what `board` and `style` contain, and that the text arrives already in capitals and clipped to its column) is in the header comment of `src/cards/board.js`; keep the export `renderBoard` and its signature, and update the comment where you change what it says. `src/demo/sample.js` has `sampleDepartures()` and `SAMPLE_NOW`; `scripts/docs.js` will write `docs/card-departures.svg` from them later (not your job).

What the board looks like (the user's brief): a dark panel, amber and white flap characters, the flap seam line, four columns TIME, DESTINATION, PLATFORM, STATUS (HORA, DESTINO, ANDÉN, ESTADO in Spanish: the labels arrive localized in `board.columns[].label`). Think of an old railway station departures board and its split-flap letters: every character sits on its own little dark tile with a thin horizontal seam across the middle where the two flaps meet, a slightly lighter top half and a darker bottom half, small gaps between tiles, a subtle bevel. A title bar on top (`board.title`, with a tiny train glyph in the `icon` color, drawn with SVG shapes), column headings in small caps style under it, then one line per row. Rows are `board.rows`; `board.empty` is shown on an otherwise empty board when there are none. The status text is colored by the row's `tone`: `boarding` uses the `title` color (amber), `on-time` the `icon` color, `delayed` the `ring` color, `departed` is the `text` color dimmed (opacity around .45). Time, destination and platform use the `text` color. The panel is `background`. Those five colors are the card's colors (the user can change each one), so every color you paint must come from them: use them as they are or blended/dimmed (opacity, `color-mix` is fine only if you also provide a fallback; plain opacity layers are safest). The only fixed colors allowed are pure black and white layers at low opacity for bevels, seams and shadows.

Animation on load, CSS only (no SMIL, no script): a subtle split-flap flip. For example each character tile's glyph flips in from `scaleY(0)` (with `transform-box: fill-box; transform-origin: 50% 50%`, so it folds around the seam) or its top and bottom halves fold in turn, with a small per-character and per-row `animation-delay` so the board seems to settle from left to right and top to bottom, finishing within about 1.5 s. It must be **visible by default**: use `animation-fill-mode: both` with keyframes whose end state is the final look, so a viewer that does not run animations (or screenshots the card) still shows the complete board. Inside `@media (prefers-reduced-motion:reduce)` set `animation:none` on everything that animates.

Layout notes: the card is as wide as it needs to be for the columns (the column widths are in flap characters: `columns[].cells`; leave a gap between columns), about 560 px wide, and as tall as its rows (a title bar, a heading line, then rows of tiles about 26 px apart). The root element must be `<svg width="W" height="H" viewBox="0 0 W H" ...>` with integer W and H, `role="img" aria-labelledby="t"` and `<title id="t">` holding `board.aria` (as `shell()` in cards.js does). Draw one rounded panel with the thin border controlled by `style.border` (`stroke-opacity` .25 on, 0 off, as the other cards do). Use the same font stack as the other cards (`FONT` is exported from `cards.js`), bold, in a monospace-feeling layout: each character is centered in its own tile (`text-anchor="middle"`), so columns line up exactly whatever the glyph widths are. Every string that reaches the SVG goes through `esc()`. Keep the file small: aim for under 25 KB for six rows; draw the tile backgrounds and seams with a few `<path>`s or `<use>` of a `<symbol>`, not with hundreds of long elements.
