Medellín Metro in ten runs

Ten runs across three tools: Claude Code, Codex and Antigravity. All received the same brief, word for word: design the Medellín Metro CAF train and the city skyline using the docs/ai/train.md and docs/ai/skyline.md guides and the same two images. Each worked in its own folder from the same commit, free to validate and render as many times as it wanted.

GPT-6-Astra and GPT-6.1-Sol · Codex

Most complete

A train with all four CAF features and a skyline with every landmark drawn. Astra did it in 4 min 48 s with 10.6k output tokens.

GPT-6.1-Terra · Codex

Most efficient

A 4/4 train in 2 min 13 s, with 3.6k output tokens and only 475 reasoning tokens, even at xhigh. Its skyline was incomplete.

Sonnet 5.5 · two tools

The tool matters

With the same prompt, Sonnet scored 4/4 in Claude Code and 1/4 in Antigravity, where it finished in a minute and a half with one render.

Haiku 5.5 · Claude Code

What the test shows

  • Codex produced the most faithful trains with the least output. Three of its four models (Sol, Terra and Astra) have all four features, with between 3.6k and 14.2k output tokens; the other six spent between 7.9k and 81.8k.
  • More reasoning did not buy fidelity. Haiku (70,000 reasoning tokens) and Gemini 4 Argon (54,000) delivered less faithful trains than GPT-6.1-Terra, which used 475 for reasoning.
  • Yellow and green together were the hardest test: only 4 of 10 included both (Sonnet in Claude Code, Sol, Terra and Astra). The rest kept one and gave the other row to the language stripe.
  • The four recognizable skylines (Opus, Sol, Astra and Argon) drew landmarks one by one with rows. None of those relying on catalog shapes reached that point.
  • The tool matters as much as the model: the same Sonnet went from 4/4 to 1/4 when switching from Claude Code to Antigravity.
  • This is one run per model: a sample, not an average. Style can change from one run to another.

Tokens: in Claude Code, counts were summed from each run's log, once per model call; in Codex they come from the turn.completed event of codex exec --json; in Antigravity, from the result of agy -p --output-format json. "Input" is all processed input, including cache. Each tool uses cache differently, so that column is best compared within the same tool.

Effort: Claude Code and Codex ran at xhigh; in Antigravity the maximum each model offers is high. Codex ran with the user's global configuration. Antigravity ran with session-only permissions: commands without asking but within its sandbox, and writing only in the comparativa/ folder.

Time: in Claude Code, from first to last message; in Codex, from startup to last event; in Antigravity, from startup to process end. Validations and renders are as reported by each model. Train and skyline scores are a visual review, not an automatic metric. Monetary cost was not calculated: each model has its own rate per token.
